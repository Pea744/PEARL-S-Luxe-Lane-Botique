# Pearl's Luxe Lane Boutique

## Project Overview

Pearl's Luxe Lane Boutique is a fashion website created for young adult women and girls in emerging adulthood. The website provides a modern and attractive way for users to explore fashionable clothing and accessories.

## Target Audience

The target audience is young adult women and girls in emerging adulthood who are interested in fashionable, modern, trendy and stylish clothing.

## Website Features

- Home page
- About Us page
- Products page
- Enquiry page
- Contact page
- Product images
- Website navigation
- Enquiry form
- Contact information
- Responsive and attractive styling

## Product Categories

The website includes:

- Dresses
- Skirts
- Tops
- Jeans
- Streetwear
- Accessories

- HTML5
- CSS3
- JavaScript

## Website Goals and Objectives

The goal of the website is to create a modern, attractive and user-friendly online fashion boutique for young adult women and girls in emerging adulthood.

The objectives are to:
- Display fashionable clothing and accessories.
- Allow users to browse different product categories.
- Provide clear information about the boutique.
- Allow users to make product enquiries.
- Provide contact information for the boutique.
- Create an easy-to-navigate and visually appealing website.
